# Import existing Safe

If your are connected with a wallet that is the signer of an existing Safe, you can import it into Ash Wallet by clicking on the **Add Safes** button.

![Add Safe](/img/ash-wallet-add-safes-1.png)

You can then see the list of Safes that you are the signer of and import them into Ash Wallet by ticking the checkbox next to the Safe and clicking on the **Save** button:

![Add Safe](/img/ash-wallet-add-safes-2.png)
