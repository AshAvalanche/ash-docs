# Manage signers

To add / remove signers or change the threshold from a Safe, you can navigate to the **Settings** page of the Safe account. And click on the **Manage signers** button.

![Manage signers](/img/ash-wallet-manage-signers-1.png)

You can then use the wizard to add / remove signers and change the threshold of signatures required to sign a transaction.
